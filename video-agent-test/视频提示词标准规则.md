# 视频生成提示词标准规则

## 核心原则

### 1. 角色外观描述禁令

**严格禁止在提示词中描述角色的服装、配饰、发型等外观细节。**

- ❌ 禁止：描述"深色针织长袖上衣"、"深灰色宽腿长裤"、"黑色软底平底鞋"等服装细节
- ❌ 禁止：描述"深色长发松散垂落"、"左手腕一条细银手链"等配饰发型
- ❌ 禁止：描述"深色修身西装外套"、"白色衬衫"等任何服装颜色、款式
- ✅ 正确：仅引用参考图，如"以 @图2 为唯一立绘参考"

**原因：**
- 文字描述会与参考图产生冲突，导致生成结果不稳定
- 参考图已包含完整的角色外观信息（服装、发型、配饰、体型）
- 模型应完全依赖参考图的视觉信息，而非文字描述

### 2. 正确的角色引用方式

**标准格式：**
```
@图N 是 [角色名] 角色 DNA（仅取面部/发型/身材/[特殊标注]）
```

**在场景描述中引用角色：**
```
@图2 Sylvia（以 @图2 为唯一立绘参考：[仅描述年龄段、性别、特殊身体状态如孕肚]）
```

**示例：**
- ✅ 正确：`@图2 Sylvia（以 @图2 为唯一立绘参考：二十多岁女性，腹部微隆）`
- ❌ 错误：`@图2 Sylvia（二十多岁女性，深色针织长袖上衣，深灰色宽腿长裤，黑色软底平底鞋，深色长发松散垂落，左手腕一条细银手链）`

### 3. 可描述的角色信息

**仅允许描述以下内容：**
1. **年龄段**：二十多岁、三十岁左右、五十岁左右
2. **性别**：女性、男性
3. **特殊身体状态**：腹部微隆（孕肚）、体型宽壮、身高差异
4. **气质**（非外观）：气质沉稳、权威感

**禁止描述：**
- 服装：任何衣服、鞋子、裤子的颜色、款式、材质
- 配饰：手链、项链、耳环、手表等
- 发型：长发、短发、扎起、散落等
- 面部特征：眼睛颜色、鼻梁高低、嘴唇形状等（这些应由参考图决定）

### 4. 新角色无参考图的处理

**当新角色没有参考图时：**
```
本镜新增人物 [角色名] 以轮廓型差异区分（无立绘）：
- [角色名]——[年龄段][性别]，[体型特征]，[气质描述]
```

**示例：**
```
Huxley——三十岁左右男性，体型宽壮明显高于其他人，气质沉稳
```

**注意：** 即使无参考图，也应尽量避免详细服装描述，仅描述体型和气质差异以便区分角色。

## 提示词结构标准

### YAML 元数据
```yaml
shot_id: ep[N]_shot_[N]
duration: [N]s
mode: 单首帧 + 多层 reference / L3 首尾帧双锚 + 三层 reference
scene: [场景名称]
shot_function: |
  [本镜的叙事功能]
prev_shot_recap: |
  [上一镜末尾状态]
next_shot_setup: |
  [下一镜开场设定]
emotion_arc: [情绪弧线]
assets:
  images:
    - [参考图路径1]
    - [参考图路径2]
  videos: []
```

### 提示词正文结构

1. **版权 + 风格声明**
2. **人物唯一性铁律**
3. **@图N 说明 + 空间关系**（禁止服装描述）
4. **核心叙事总纲**
5. **关键场景时间轴（故事线）**
6. **关键场景分镜**（禁止服装描述）
7. **音效层**
8. **禁止事项**

## 并发生成规则

### 1. Shot 间禁止并发（选择分支除外）

**严格禁止在同一集内的顺序 shot 之间并发生成视频。**

- ❌ 禁止：同时生成 EP3 的 shot_1 和 shot_2
- ❌ 禁止：同时生成 EP5 的 shot_3 和 shot_4
- ✅ 正确：按顺序生成 shot_1 → shot_2 → shot_3

**原因：**
- 顺序 shot 之间需要接续上一个 shot 的尾帧
- 并发生成会导致后续 shot 无法获取前一个 shot 的尾帧
- 必须等待前一个 shot 生成完成后才能开始下一个 shot

**例外：选择分支 shot 可以并发**

选择节点后的不同选项分支可以并发生成，因为它们都从同一个选择节点 shot 的尾帧开始。

- ✅ 正确：同时生成 EP1 的 shot_5a 和 shot_5b（都接续 shot_4 的尾帧）
- ✅ 正确：同时生成 EP2 的 shot_4a、shot_4b_fail、shot_4b_pass（都接续 shot_3 的尾帧）
- ✅ 正确：同时生成 EP5 的 shot_5a、shot_5b_fail、shot_5b_success（都接续 shot_4 的尾帧）

**选择分支并发的前提：**
- 选择节点前的 shot（如 shot_4）已经生成完成
- 已获取选择节点 shot 的尾帧
- 所有分支 shot 都使用同一个尾帧作为起始帧

### 2. Episode 间允许并发

**允许在不同集数之间并发生成视频。**

- ✅ 正确：同时生成 EP3 的 shot_1 和 EP5 的 shot_1
- ✅ 正确：同时生成 EP7 的 shot_2 和 EP9 的 shot_3

**前提条件：**
- 这些集数不需要接续上一集的尾帧（参考集数列表：EP1, EP3, EP5, EP7, EP8, EP9, EP11, EP17, EP18, EP20）
- 或者已经获取了上一集的尾帧

### 3. 并发生成确认机制

**在并发生成视频前，必须得到用户明确的"确认"二字才能执行。**

- ❌ 禁止：未经确认直接并发生成
- ❌ 禁止：用户说"好的"、"可以"等模糊回复就开始生成
- ✅ 正确：用户明确回复"确认"二字后才开始并发生成

**标准流程：**
1. Agent 提出并发生成计划（列出具体的 episode 和 shot）
2. 等待用户回复"确认"二字
3. 收到"确认"后才执行并发生成

**示例对话：**
```
Agent: 我计划并发生成以下视频：
- EP3 shot_1
- EP5 shot_1
- EP7 shot_1

这些集数都不需要接续上一集尾帧。请回复"确认"以开始并发生成。

User: 确认

Agent: [开始并发生成]
```

## 检查清单

在提交提示词前，请确认：

- [ ] 没有描述任何角色的服装（衣服、裤子、鞋子）
- [ ] 没有描述任何角色的配饰（手链、项链、耳环）
- [ ] 没有描述任何角色的发型细节
- [ ] 所有角色引用都使用"以 @图N 为唯一立绘参考"格式
- [ ] 仅描述了年龄段、性别、特殊身体状态
- [ ] 参考图路径正确且文件存在
- [ ] 如果是并发生成，已获得用户"确认"二字
- [ ] 如果是同一集内的 shot，按顺序生成而非并发
