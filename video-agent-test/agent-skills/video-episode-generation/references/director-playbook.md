# Seedance 实测可用的导演原则

本文件只收**Seedance 2.0 实测能稳定生成**的导演技巧。

写 prompt 前按本文件 8 条对照——命中哪条就用哪条，**不要发明 Seedance 做不到的镜头**。

---

## 一、镜头语言（Seedance 强档可控）

### 1. 景别收紧阶梯

情绪强度推进时**用景别变化承载**，不要靠表情堆砌（表情是弱档）。

| 戏剧情境 | 阶梯 | 禁止 |
|---|---|---|
| 对话博弈 | 全景（建立空间）→ 中近景（剥离环境）→ 特写（灵魂时刻） | — |
| 独白内心 | 全景 → 中远景 → 中近景（**渐进推 · 禁止跳级**） | 直接给特写（破坏沉浸节奏） |

景别变化属于 Seedance 强档（≥20cm 等级），是控情绪曲线最稳的工具。

### 2. 一段对话戏天然拆多镜

完整"建立→锁定→灵魂"三档景别阶梯单 shot 装不下 12s——**必须拆 2-3 个连续 shot**。

写 prompt 前判断本镜在阶梯哪一档：
- 建立段：景别保持全景/中远景，台词承载信息
- 锁定段：中近景，台词承载冲突
- 灵魂段：特写，台词承载情感顶点

不要试图在一镜里完成全程。

### 3. 多角色 Z 轴错落深度站位

三人以上同框 → 前-中-后景**Z 轴错落**，不要一字排开。

实操：
- 前景 1 人（中景，主体）
- 中景 1 人（半身，次主体）
- 后景 1 人（远景剪影或模糊轮廓）

Seedance 强档能控（属于站位/构图层）。一字排开会让画面平、人物分量等同、剧情主体丢失。

### 4. 工业欺骗法 = 主体静止 + 背景流动

**Seedance 高速动态戏唯一稳定生成方式**——所有跑/飞/追/打都要走这个公式。

| ❌ 禁止写 | ✅ 改写 |
|---|---|
| "角色快速奔跑" | "角色顶风站立 + 头发飞扬" |
| "飞车呼啸而过" | "角色坐定不动 + 车窗外景物动态模糊疾驰" |
| "拳脚交锋" | "两角色站位锁定 + 镜头侧向震 + 衣料掀起风" |

完整公式：**主体相对镜头静止 + 头发/衣料因风微动 + 背景动态模糊 + 侧向间断光斑闪烁**

卡车拍摩托的逻辑——运动感全靠背景，主体永不真动。

### 5. 三重静止收尾

每镜结尾 2 秒：

1. 镜头完全停止移动
2. 角色完成最后动作后保持不动
3. 画面构图锁定到视频结束

给观众消化时间，让情绪余韵沉淀。**所有 shot 必须有此收尾**——这是 Seedance 防"末段抽帧/瞬移"的硬性技术约束，不是审美选择。

## 二、剧作 / 声音 / 色调

### 6. 重大情绪时刻减声原则

真相揭露 / 背叛瞬间 / 致命对白 / 仪式化停顿 → **配乐瞬停 + 环境音骤降 + 心跳或挂钟作为唯一声源**

反向：不要堆煽情管弦乐渲染情绪——**用静默承载**。

实测验证：shot_1b_v6 7-9s 仪式化停顿（环境音骤降+挂钟滴答+配乐瞬停）效果远好于 v3-v5.1 大提琴悲情单音。

### 7. 画外音独白结构

公式：**voiceover（音频独白·无字幕）+ 主角缓慢微动作**

主角动作选项（任选 1-2 个）：
- 手中物体动作缓缓停下
- 目光虚焦投向窗外某点
- 呼吸深长一次
- 手在围裙/衣料上轻擦

**外加铁律**：独白镜头**禁止大特写**——保留环境呼吸（中景/中远景），给孤独感留空间。压缩独白人物会让观众感到压迫而非沉浸。

### 8. 结局色调差异化锚定

互动剧多结局必须**视觉差异化**让玩家感受到决策的画面回报：

| 结局类型 | 色调 |
|---|---|
| True Ending | 暖金色调 + 黄昏光 |
| Bad Ending | 冷蓝降饱和 + 孤立色温 |
| Secret Ending | 高反差黑白 + noir 阴影 |

**实现方式：靠场景图选色调**（同一场景做三种色调版本），不是靠 prompt 文字写"3200K vs 5600K"——色温/光温是 Seedance 弱档不响应。

## 三、镜头角度与出场设计

> 以下原则来自电影镜头语言分析，在本项目 Seedance 实测数量尚不足 3 次——**按"建议尝试"使用，稳定验证后升格为正式原则**。写 prompt 时优先用具体物理描述而非抽象分类词（见各条写法提示）。

### 9. 镜头角度情绪速查

**角度 + 景别才是完整的镜头语言**：角度决定情绪基调，景别决定情绪强度，二者配合使用。

| 角度 | 情绪 / 叙事功能 | 互动动漫典型场合 |
|---|---|---|
| 低机位仰视 | 力量感、英雄气势积累 | Alpha / Boss 出场、权力反转时刻 |
| 俯视 | 控制、压制、弱势感 | 弱势角色被逼退、命令压制戏 |
| 背面角度 | 孤独、神秘、未知 | 独白戏、主角直面命运的定格 |
| 斜角（Dutch angle） | 心理失衡、惊悚、不安 | 背叛揭露瞬间、真相冲击时刻 |
| 侧面 | 压抑、欲言又止、思考 | 内心戏留白（比正面克制，张力更足） |
| 过肩反打（OTS） | 对话代入，强化戏剧张力 | 关键对话选择支（让玩家站在角色视角） |
| 虫眼仰拍 | 力量压迫、空间纵深 | Boss 全身出场、权威空间（议事厅） |

**Seedance 写法提示**：
- 写"镜头从膝盖高度缓慢抬升至面部"比写"仰视镜头"更容易响应
- 写"画面向右倾斜约 12 度，水平线歪斜"比写"斜角镜头"更具体
- 过肩反打写"镜头越过 A 的左肩，朝向 B 的面部"（明确哪侧肩膀）

### 10. 人物出场三模式

| 模式 | 镜头设计 | 适用场合 |
|---|---|---|
| 英雄出场 | 低机位起，缓慢抬升至面部 | Alpha / 主角首次展现气势 |
| 神秘出场 | 背面起，利用轮廓 / 环境构图，缓慢扫视 | 隐藏身份、悬念人物、反派登场 |
| 环境交代出场 | 平视跟拍 + 侧向环绕组合，展示人物与场景关系 | 新场景首镜、交代势力地盘 |

**铁律**：出场首帧一定是"人物局部 / 轮廓 / 背面"——完整正面留给揭晓瞬间，制造期待。

### 11. 对话镜头两个进阶技巧

**技巧 A：用对白强化背景**
先用对白建立人物关系 / 情绪，再接高位下降镜头揭示危险环境——让环境成为对白的视觉注脚（先说话，后看场景）。

**技巧 B：用背景强化对白**
先拍压迫性环境（废墟 / 火光 / 黑暗），再绕镜头到角色面前——背景重量前置，角色开口时观众已有情绪基底（先看场景，后看角色）。

## 四、入场设计与动作链拆镜（实测稳定）

### 12. 入场路径与障碍物绕行（人物从画外进入画面时强制）

**问题**：人物从画外推门入画时，prompt 只写"X 推门走入画面到 Y 位置"——模型不知道画面里已经存在的物体（侧翻椅子/散落文件/桌角）和入场路径的空间关系，会让人物**直接穿过障碍物**。

**根因**：场景空间地图段落（见 SKILL.md Step 3）描述了画面里有什么，但**入场动作的"路径"是新引入的几何信息**，模型不会自动从空间地图推导出避障路径。

**SOP（人物从画外进入画面时必填）**：

1. **写"路径"**——入场动作必须写：`X 从画面 Y 边缘的 [门/通道] 入画 + 经过 Z 路径 + 到达 W 位置`
   - 例：`Huxley 从画面右下角的入口推门入画，经过画面右侧地板（贴右墙绕开侧翻在画面中央偏左的椅子），到达 Sylvia 跪倒位置（画面中下）`
2. **障碍物绕行明示**——⑥段写时间段绕行：`t1-t2 秒 X 从画面 A 侧通过，绕过障碍物 B`
3. **⑧段加禁**：`禁 X 穿过障碍物 B / 禁 X 与 B 发生肢体重叠 / 禁 B 在 X 入画过程中消失或位移`
4. **障碍物引用空间地图坐标**：用空间地图段落里建立的画面分区（"画面左下 1/3"/"画面中央偏左"）描述障碍物位置，入场路径用同一坐标系

**翻车案例**：EP5 shot_5 v1（Huxley 推门 + 跪地 + 双对白 + 抱起 + 转身）只写"Huxley 推门入画跪到 Sylvia 旁"——但 shot_4b 末帧画面中央偏左是侧翻的椅子。出片 Huxley 直接**穿过侧翻椅子**走过去。v2 加入"Huxley 从画面右下角入画 + 贴右墙绕过画面中央偏左的侧翻椅子 + 到达 Sylvia 跪倒位置"，⑥段每段标注绕行路径，⑧段禁"Huxley 与椅子发生肢体重叠"，问题修复。

### 13. L4 突发动作链拆短镜（单镜 ≤ 6s + 强档动作 ≤ 4 个）

**问题**：L4 突发动作链镜（眩晕昏倒、打斗、坠落、突发跌倒）单镜 12s + 6 个强档动作（眩晕预兆 → 文件滑落 → 椅子翻 → 坠地 → 护腹 → 静止）的翻车率经验估 **30-50%**——动作链中段抽帧、姿态跳变、伴随物消失（见 #15）多重叠加。

**SOP**：

- L4 突发动作链镜**强制拆 2-3 个短镜**：单镜 ≤ 6s，单镜内强档动作 ≤ 4 个
- 拆分点选**自然的动作终止**（站立 → 椅子翻完静止 → 坠地静止），不要在连续动作中段拆
- 拆出来的子镜按 `shot_{n}a / shot_{n}b` 命名（见 shot-id-policy.md）
- 子镜之间用末帧 PNG 承接（首镜末帧 → 续镜首帧），不依赖视频 URL 承接（跨子镜的动作惯性 Seedance 解析也不稳定）

**翻车案例**：EP5 shot_4 原计划单镜 12s 跑完"眩晕预兆 → 文件滑落 → 椅子翻 → 坠地 → X 形护腹 → 静止"——预估翻车率 30-50%，决策拆为：
- shot_4a（6s）：眩晕预兆 + 文件滑落（4 个动作内）
- shot_4b（6s）：椅子翻 + 坠地 + X 形护腹（4 个动作内）

拆完后单镜均通过，shot_4a 仅在音频侧翻车 3 次（见 seedance-lessons.md #16），画面侧无问题。

## 与外层规则的关系

- 本文件提供 Seedance 导演原则：第 1-8 条与第 12-13 条为实测稳定，第 9-11 条为待验证建议
- 三重静止（第 5 条）与外层 E-9 重叠 · 都执行
- 写 prompt 时景别选择必须在第 1/2 条阶梯框架内
- 高速动态戏必须走第 4 条工业欺骗公式
- 入场动作必须走第 12 条；L4 突发动作链必须先按第 13 条拆镜再写 prompt
- 第 9-11 条实测稳定 3 次以上后去掉"待验证"标注，升格为正式原则
