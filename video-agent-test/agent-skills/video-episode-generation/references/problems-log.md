# Seedance 真实问题汇总

来源：EP1-EP6 生成实录 · 手写 vs 结构化 prompt 对比测试（对比test.xlsx）· 逐帧分析
每条问题基于实际观察或用户直接标注，不是推断。

---

## 一、Prompt 写法问题

### 1. 手写 Prompt 无固定结构 → 输出不可预测

手写 prompt 是连续叙事段落，每次结构不同，信息顺序随手感变化。
模型对同样内容的注意力分配每次不同，输出变化难以预测和复现。

**结构化 prompt（时间戳分镜格式）的解法：**
```
【镜头1 · 0-2s · 全景 · 静止】场景建立
【镜头2 · 2-7s · 中景 · 缓慢推近】核心表演段
【镜头3 · 7-11s · 中远景 · 平移跟拍】收尾
```
给模型可预测的叙事骨架，每段注意力分配稳定，镜头切换和运镜更可控。

**来源：** 对比test.xlsx ep1/ep2 结构化版本的镜头调度明显优于手写版

---

### 2. 台词总量超出视频时长承载上限

**实际案例（对比test.xlsx ep1）：** 手写版 prompt 在 15s 内同时塞入了画外音独白 + James 的三轮对话 + Sylvia 的两轮回应 + 动作描述，评注："台词太长了，15s 几乎无法同时容纳画外音和男主角的对话信息。"

视频时长是固定的物理约束。台词量 + 动作量 + 镜头切换共享同一时长——塞得越多，每项完成度越低。

**规则：** 写 prompt 前先估算纯台词时长（正常语速 1 字/0.3s），留出动作和镜头过渡时间，确认能装进 duration。

---

### 3. Prompt 表演段被辅助内容挤占

空间约束 / reference 分工 / 禁忌清单若超过 prompt 总长的 50%，模型对表演段（情绪 + 台词 + 动作）的注意力不足，渲染退化。

**实际案例：** shot_1b_v5 加入大段空间约束文字后，情绪渲染退化到 v3 水平；v5.1 删除冗余约束后恢复。

**规则：** 表演段占比 ≥ 50%；辅助内容合计 ≤ 50%。超出 → 砍禁忌清单，不砍表演段。

---

### 4. 多变量同时修改 → 无法定位根因

**实际案例：** shot_1b_v5 同时改了模型版本（standard→fast）+ 参考图数量 + prompt 文字量，退化后无法判断是哪个变量导致的。逐一还原后确认是模型降级。

**规则：** 架构验证每次只改一个变量。

---

## 二、模型渲染能力边界

### 5. 所有情绪状态压平为同一张中性脸

**视觉证据：** shot_8_end / shot_9_end — Sylvia 目击 James 在新坟旁抱着 Kennedy，全剧情绪顶点。她的表情：平静，手放肚子，如在等电梯。

这不是"prompt 情绪写错了"。是 **Seedance 把所有复杂情绪压缩成最稳定的中性输出**，因为中性脸生成稳定性远高于表情戏。

**对比test.xlsx ep2 手写版** 评注："人物刻画感会更强烈一些，给到了 Sylvia 的肚子特写和面部表情的特写"——这是相对而言较好的结果，但绝对值仍然不够。

**目前无完美解法：**
- 弱档表情（≤5cm）稳定性仅 ~30%
- 反向校准 ×2 只能在"微弱可见"和"勉强看到"之间移动
- 首尾帧双锚是唯一能硬绑表情状态的方案，代价是失去动态

---

### 6. 相邻镜头构图同质化

**视觉证据：** shot_8_end ≈ shot_9_end，两帧几乎相同构图。

两个连续镜头，不同台词，不同情绪指向，生成了同一张画。
模型对"场景 + 人物组合"找到稳定解后锁定，不再响应细微叙事差异。

---

### 7. 弱档动作堆叠 → 全部稀释

同一镜头超过 2 个弱档动作（≤5cm，如含泪 / 颤抖 / 嘴唇颤），每个分到的注意力权重 ≈ 10%，全部落不了地。

**规则：** 情绪主体靠强档动作（≥20cm）承载；弱档最多保留 1 个作为点缀。

---

### 8. 情绪强度衰减 → 需反向校准 ×2

Seedance 渲染强度 ≈ prompt 描述的 50%。
- 写"含泪" → 出片几乎看不出
- 写"眼眶湿润度 100%，一颗泪悬在睫毛上欲落不落" → 刚好可见

**公式：** prompt 写的强度 = 目标强度 × 2
仅对弱档情绪 / 微表情有效。强档大动作过度描述反而崩。

---

## 三、空间 / 时间连续性失效

### 9. 人物在镜头间瞬移，站位不符叙事逻辑

**视觉证据：**
- shot_5_end：Sylvia 在墓碑后远处偷看，James 在深景跪着
- shot_8_end：Sylvia 突然站在 James 旁边一米处

中间无任何空间过渡，直接传送。
站位本身也不对——她刚从墓碑后偷看，此时不应已走到他们身旁。

**对比test.xlsx ep5 手写版** 评注："女主倒下的地方 和 男主抱起她的画面没有保持一致"——同一 shot 内部也出现了位置跳变。

**根本原因：** 每个 shot 独立生成，末帧 PNG 只锁交接瞬间的姿态，不锁全局站位关系。模型自行决定人物在画面中的位置，不参照前一镜的空间逻辑。

---

### 10. 人物在场景末段消失——空场景 end frame

**视觉证据：**
- shot_2b_end = 空厨房，只有蔬菜和橱柜
- shot_4_end = 空厨房，同样无人

本应有 Sylvia 的场景，end frame 里一个人都没有。
下一镜用这个末帧做时间承接，人物姿态锚点丢失，接续断掉。

---

### 11. 关键情绪时刻把人物脸藏掉

**视觉证据：** shot_6a_end = Sylvia 背对镜头，脸完全不可见。

Sylvia 第一次目击 James 跪抱 Kennedy——观众最需要看到她表情的那一帧，镜头给了后脑勺。
模型自行选择了背影构图（背影比表情稳定得多）。

---

### 12. 画外音空间感无法渲染

**对比test.xlsx ep3 结构化版本** 评注："对女主的特写比较生动清晰，但是很难捕捉到信息来自于走廊的两个人。"

剧情需要：Sylvia 在厨房，听到走廊里两个人说话——声音有明确的空间来源方向。
模型无法区分"走廊传来的对话"和"同一房间内的对话"，空间感在生成结果里消失了。

---

### 13. 开门 / 物理穿模

**对比test.xlsx ep1 结构化版本** 评注："存在开门穿模的问题。"

门开关动作时，门板与人物肢体发生穿插——模型对门的物理运动轨迹和人物站位的空间关系计算不准确。

---

## 四、角色一致性

### 14. 模型自行添加或修改服装

**对比test.xlsx 评注：**
- ep1 结构化版本："莫名其妙增加了女主角的围裙"——prompt 和立绘里均无围裙
- ep2 结构化版本："模型自行修改了 Kennedy 的着装"

与参考图不符的服装被模型自行生成，且不可预测。

**注意：** 这与"版本间服装漂移"是两个不同的问题——这里是同一次生成内模型凭空添加了不存在的服装元素。

---

### 15. 参考图超过 4 张 → 文本注意力被稀释

参考图每多一张，文本 prompt 对表演层的注意力被分走一份。超过 4 张后情绪 / 台词渲染明显退化。

**规则：** 上限 4 张（空间地图 + 末帧承接 + 1-2 张角色立绘）。

---

### 16. @图N 重复引用 → 角色分身

一条 prompt 里多次 `@图1` 引用同一立绘，模型把每次 @图1 视作"再注入一个该立绘实例"，画面出现多个外形相同的人物。

**规则：** 每个角色 `@图N` 仅用一次（首次登场句），之后裸写角色名。

---

### 17. 道具 / 动作提前激活 → 剧情穿帮

创伤触发的动作（如摸银手链）在激活时间点前写进 prompt，观众看到无缘由的反射动作，产生困惑。

**规则：** 每个 symbol 标注 `trauma_activation_after: shot_X`，激活点前严禁写触碰动作。

---

## 五、台词 / 音频

### 18. TTS 台词节奏失控——语速过快或停顿错位

**对比test.xlsx ep1 结构化版本** 评注："男主的台词节奏感也不对，说的非常匆忙。"

James 的台词应是克制、沉着的离开，结果 TTS 生成了急促语速。

**核心原因：TTS 不响应语气形容词，只响应句式结构。**

| 情绪 | ❌ 无效写法 | ✅ 有效写法 |
|---|---|---|
| 克制 / 沉着 | "语气平静地说" | `Alpha Barnes passed. I have to go.`（短句，无破折号，无停顿符） |
| 压抑 | "平静但内心痛苦地说" | `I know. I've always known.`（短句 + 句号停顿） |
| 崩溃 | "颤抖着哭泣地说" | `It's not— it's not what I thought.`（自我打断） |
| 强装镇定 | "勉强撑着说" | `Everything is fine. Everything is—`（骤然截断） |

**停顿工具：** `...` = 情绪悬挂；`——` = 自我截断 / 被打断。停顿符号也会衰减——想要"明显停顿"，需要连用（`I know... I know...`）。

---

### 19. ARK 视频输入被真人检测全面拦截

任何 `@视频1` 输入 → `InputVideoSensitiveContentDetected`，一律拒绝。动漫 / 风格化视频无豁免。

**解法：** `videos: []` 永远为空。时间承接用末帧 PNG（`{作品}/episodes/ep_{N}/end-frames/{shot_id}_end.png`）。

---

### 20. TTS 英文敏感词触发音频审核失败

`"Stay. This one's mine."` → `OutputAudioSensitiveContentDetected`（mine = landmine 同音）

高风险词：`mine / shot / gun / kill / drug / dead / blood`

**解法：** 写完对白先过一遍敏感词清单，命中主动改写。两次失败后 `--no-audio` 静音生成，剪辑阶段补 BGM。

## 六、镜头调度

### 21. 镜头注意力分布不均——后半段特写挤占全镜叙事

**对比test.xlsx ep6 结构化版本** 评注："剧情表达流畅完整，但是更侧重于后半部分女主将手中的纸折叠起来的特写动作。"

结构化 prompt 中，对最后动作（折纸）的描述最精细，模型将注意力集中在此，前段的多人互动叙事被压缩。

**规律：** 模型倾向于优先渲染 prompt 末尾的动作，或描述最具体的那段。叙事重心靠描述密度体现——重要段落写得细，次要段落写得粗。

---

## 七、EP5 实测新增问题

### 22. 俯视/大特写镜头退化为正俯航拍或纯平面贴图

**视觉证据**：EP5 shot_2 v1（手背压痕特写）写"近俯角 30° 俯视桌面"——出片是绝对水平的平面贴图，桌面无纵深，手腕到指尖比例失真。

**根因**：Seedance 对俯角度数的语义解析弱，遇到俯视描述退化到训练分布最稳定的两个解：航拍 90° 或平面贴图。文字层抽象俯角词不响应。

**SOP 沉淀**：`references/seedance-lessons.md` #14（写"摄像机位置 + 几何夹角"，禁抽象俯角词）。

---

### 23. 大幅运动末段伴随物（椅子/桌子/文件）"凭空消失"

**视觉证据**：EP5 shot_4b v1（椅子翻倒 + Sylvia 坠地 + 护腹）末段椅子完全消失，只剩 Sylvia 单独跪在空地。

**根因**：Seedance 偏好"画面焦点清晰简洁"。主体姿态被反向校准 ×2 强调时，模型为突出主体会主动"清掉杂物"——主体越被强调，伴随物越易被清场。

**SOP 沉淀**：`references/seedance-lessons.md` #15（⑥段每段持续锁定 + 三重静止收尾构图层并置 + ⑧段专项防御 + 赋予叙事价值）。

---

### 24. L4 突发动作链音频是模型生成层根因，与 prompt 文字几乎无关

**视觉证据**：EP5 shot_4a（眩晕预兆 + 文件滑落，6s 突发动作）连续 3 次返 `OutputAudioSensitiveContentDetected`。前两次⑦段写了"中性"动作音描述（"文件滑落到地的轻响"/"短促吸气"），仍被拦截——因为模型实际生成的滑落音和吸气音被自家安全模型识别为危险信号。

**根因**：ARK 安全过滤不基于 prompt 文字，基于模型实际生成的音频流内容。画面有失控内容 → 模型自动生成对应敏感音效 → 被拦截。

**与问题 20（TTS 英文敏感词）的区别**：20 是文本层（改对白可绕过），本条是音频生成层（必须从画面动作强度入手）。

**SOP 沉淀**：`references/seedance-lessons.md` #16（⑦段照抄静止镜的"安静"模板 + fast 模型 + ⑧段禁动作拟声/呼吸声）。

---

### 25. 视频版权拦截 PolicyViolation 是显著概率事件

**视觉证据**：同一 prompt 多次运行结果不同——次次 PolicyViolation 发生频率约 30%，重跑 1-2 次大概率通过。

**根因**：ARK 视频版权检测有显著随机成分，不是固定拦截规则。

**与问题 24 的区别**：

| 拦截类型 | 性质 | 第一反应 |
|---|---|---|
| `OutputAudioSensitiveContentDetected` | 基本固定 | 改⑦段/⑧段 |
| `OutputVideoSensitiveContentDetected.PolicyViolation` | 显著概率 | **先重跑 1-2 次**再考虑改 prompt |

**SOP 沉淀**：`references/seedance-lessons.md` #17 + `SKILL.md` Step 8 重生决策树。

---

### 26. OSS 预签名 URL 24h 过期 → 跨日承接硬阻塞

**视觉证据**：EP5 shot_4a 与 shot_4b 跨 24h 生成，shot_4b 引用 shot_4a 的视频 URL 时报 `InvalidParameter / resource download failed` 在 `content[N].video_url`。

**根因**：上传到 OSS 的视频 URL 是预签名 URL（`X-Tos-Expires=86400`），24h 失效。

**SOP 沉淀**：`references/seedance-lessons.md` #18（跨日续镜去掉 `previous_video_url` + `assets.videos`，仅靠 `previous_frame_url` 承接）+ `SKILL.md` Step 7 加 validate 时跨日 URL 自检。

---

### 27. 人物入画穿过场景中已存在的障碍物

**视觉证据**：EP5 shot_5 v1（Huxley 推门 + 跪到 Sylvia 旁）——Huxley 直接穿过 shot_4b 末帧画面中央偏左的侧翻椅子。

**根因**：场景空间地图段落描述了画面里有什么，但**入场动作的"路径"是新引入的几何信息**，模型不自动从空间地图推导避障路径。

**SOP 沉淀**：`director-playbook.md` #12（入场动作必须写"路径"+ 障碍物绕行明示 + ⑧段禁穿过）+ `SKILL.md` Step 3.2（场景空间地图段落，入场路径与空间地图共用 9 宫格坐标系）。

---

### 28. L4 突发动作链单镜 12s 翻车率 30-50%

**观察**：L4 突发动作链镜（眩晕昏倒、打斗、坠落、突发跌倒）单镜 12s + 6 个强档动作的翻车率经验估 30-50%——动作链中段抽帧、姿态跳变、伴随物消失（问题 23）多重叠加。

**根因**：单镜动作越多，每个动作分到的注意力越少；中段动作最易被抽帧或姿态跳变。

**SOP 沉淀**：`director-playbook.md` #13（L4 强制拆 2-3 个短镜，单镜 ≤ 6s + 强档动作 ≤ 4 个；拆分点选自然动作终止；子镜间用末帧 PNG 承接）。
