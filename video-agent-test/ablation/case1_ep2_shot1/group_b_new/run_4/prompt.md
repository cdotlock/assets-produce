④ 核心叙事总纲：新月领地公墓，白昼，阴云低压，冷灰色调，整体凝滞无风。三人在石碑草地构成斜向三角站位：Sylvia 前景左侧（孕妇身形，面朝 James）；James 中景居中（与 Kennedy 相靠）；Kennedy 在 James 右侧，刚抬起头。Sylvia 是主体，在整镜拥有最多的镜头时间；James 与 Kennedy 是中景参照，承担 Sylvia 的情绪对象功能。摄像机轴线严格在 Sylvia-James 连线的左侧，全镜不越轴。

⑤ 关键场景时间轴（故事线）：
0-2s：开场定位。中景偏高机位下压（俯视），收三人入画，阴云公墓空间确立压迫基调。Sylvia 站于前景中央，初始状态为低头，手垂身侧。
2-4s：手腹动作段。Sylvia 的右手缓缓抬起，轻放在腹部；随后手指明显地收拢攥紧腹前衣料（强档，1-2秒可见），然后缓缓张开，手垂回身侧。这段动作是内心决定完成的物理外化。
4-5s：抬头段。Sylvia 的头从低垂缓缓抬起，视线升起，正面锁定 James 方向，目光收成一线。
5-7s：极平逼问段。中近景聚焦 Sylvia 侧脸，她的嘴唇动作清晰但克制（无颤抖）。TTS 对白："I need an answer, James." — 声音极平，一字一顿，James 前有明显停顿。
7-9s：三角对峙段。James 下颌绷紧，没有开口，没有松手。Kennedy 从 James 怀中抬起头（强档），向 Sylvia 方向斜视，眼神沉着且挑衅。Sylvia 视线在 James、Kennedy 之间依次扫过，在二人脸上各停顿约一秒，最终凝固在 James 脸上整整三秒——沉默是她需要的那个答案。
9-10s：主动转身段。Sylvia 轻轻开始向右旋转身体（渐变动词：缓缓），转身背对，脚步稳定踩在草地落叶上，向停车场方向走去，不快不慢，没有犹豫。James 开口（画外）"Sylvia. Stop."——她脚步无任何改变，不停，不回头。
10-12s：三重静止收尾。镜头完全停止，Sylvia 背影静止于公墓冷灰石碑间，James 与 Kennedy 立于中景，整个构图锁定至视频结束帧。

[0-2s] 开幕高机位中景（轻微俯视角），阴云铺满天空，石碑压低视野。三人 Z 轴错落就位：Sylvia 前景低头，James+Kennedy 中景相靠。
