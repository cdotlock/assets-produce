⑤ 关键场景时间轴（故事线）：
0-3s：建立段。中远景收入三人全貌——Sylvia 面向 James 站定，James 与 Kennedy 在中景。Sylvia 的手指在腹部轻轻攥紧，然后缓缓松开。
3-7s：锁定段。镜头缓推至 Sylvia 中近景侧脸，她抬起头，目光收成一道细线钉死 James 方向，嘴唇微启说出台词。James 的下颌可见地绷紧，Kennedy 从 James 怀中抬头，眼神挑衅指向 Sylvia。
7-10s：决断段。Sylvia 对视三秒，目光在 James 脸上停住，然后缓缓转身，背对画面右侧走向公墓停车场方向，脚步稳而不快。James 在中景叫"Sylvia. Stop."——她没有停，没有回头。
10-12s：三重静止收尾。镜头静止，Sylvia 背影在冷灰公墓石碑间渐远，走到画面三分之一处停下最后一帧，构图锁定，情绪余韵沉淀。

⑥ 关键场景分镜：
[0-3s] 中远景。全三人入画。阴云低压公墓，落叶铺地，石碑错落。Sylvia 前景左侧站定，手指缓缓在腹部收紧后松开（强档动作，承载内心绷紧感）。
[3-7s] 中近景推进。镜头缓推聚焦 Sylvia 侧脸。她抬起头，目光钉住前方（中档）。对白 TTS：（声音极平，一字一顿）"I need an answer, James." — 短句，停顿在 James 前。James 下颌绷紧（强档可见）。Kennedy 从 James 怀中抬起头，眼神斜向 Sylvia（挑衅中档）。
[7-9s] 三秒对视。Sylvia 目光在 James 脸上停留整整三秒，表情收紧但不崩（强装镇定：嘴唇平合，不颤）。三秒后 Sylvia 的身体缓缓向侧后方转动，开始转身。
[9-10s] 转身离开。Sylvia 转身完成，背对镜头，步伐稳定迈向公墓出口方向。James 在中景开口（画外）"Sylvia. Stop."——Sylvia 脚步不乱，不回头，不快不慢。
[10-12s] 三重静止。镜头完全停止运动。Sylvia 背影在冷灰石碑间定格，走至画面中部停止，构图静止到视频结束。
