Upload a local file to Aliyun OSS and return a permanent public https URL.

- Use this to turn a LOCAL file path produced by another tool (e.g. `cg-render`, `upscale-image`) into a permanent OSS URL, so the result can be chained into URL-only tools or returned to the user
- `local_path` must be an absolute path to an existing, non-empty regular file (typically the output of a prior tool in this run)
- Returns the bare https URL of the uploaded object
- The object key is a random UUID under `oss_prefix` (default `assets`); content-type is inferred by OSS from the key's file extension, which is taken from the local file's extension (or from `content_type` when the file has none)
- Failures (path not absolute / missing / empty / OSS upload error) surface as the tool output text — nothing is thrown
- Set `dryRun: true` to preview the resolved upload key without calling OSS (testing only — never set in production)
